はじめに、ご希望の使い方についてお伝えします。Grift は候補者の GitHub を点数化するツールではありません。点数、順位、合否は出しません。Grift の利用規範では、数値だけでの足切り、同意のない第三者のプロファイリング、組織内での監視や個人の比較を、TEP に沿わない使い方としています。恐れ入りますが、点数の高い順にクライアントへ紹介する形でのご利用はお受けできません。

Grift CLI は git 履歴から確かめられる事実を取り出す OSS（MIT ライセンス）です。候補者本人がご自分のリポジトリで実行し、その結果を本人の同意を得たうえで共有する形であれば、推薦の理由を根拠とともに伝える材料になります。点数で並べるのではなく、面談で確かめることを具体にするために使ってください。CLI は無料で、`pipx install grift-cli` でインストールできます。

紹介会社・SES 企業さまにはテスト導入（PoC）を個別にご案内しています。料金も個別にご案内します。来週からの開始をご希望の場合も、まず30分ほどのオンライン打ち合わせをお願いしています。打ち合わせでは使い方と、候補者から同意をもらう方法を確認させてください。候補日時をいくつかご提示いただけますか。日程が決まりましたら、開始日を相談させてください。

ご希望に沿えない部分があり、申し訳ありません。Grift でできることと、紹介の場での使い方を、打ち合わせで具体的にお話しします。
