先にお伝えしておきたいことがあります。Grift は候補者を点数化するものではありません。git 履歴から確かめられる事実を取り出す OSS の CLI（MIT ライセンス）で、点数、順位、合否は出しません。

そのため、点数の高い方から順にご紹介するという使い方には合いません。Grift の利用規範でも、数値だけの足切りや、本人の同意がない第三者のプロファイリングは、Grift の考え方に沿わない使い方としています。

代わりに、候補者の方がご自身のリポジトリで Grift CLI を実行し、出てきた事実をもとに、経歴や仕事の進め方について具体的に話す材料にしていただく使い方をおすすめしています。CLI は無料で、導入は pipx install grift-cli だけです。クライアントへご紹介する場面でも、点数ではなく確かめられる事実を添えて説明できます。

料金は紹介会社の皆さまにテスト導入（PoC）を個別にご案内しています。金額はこのメールには書かず、お打ち合わせでご説明します。

始める前に、30 分ほどオンラインでお打ち合わせをさせてください。使い方と、候補者の方から同意をいただく方法を一緒に確かめたいと考えています。来週からの開始はその打ち合わせの内容次第です。ご都合のよい日時を、いくつか候補でお知らせください。
