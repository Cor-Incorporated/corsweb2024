Grift CLI は git 履歴から確かめられる事実を取り出すツールで、点数・順位・合否は出しません。ご希望の「点数の高い方から順に紹介する」という用途での導入は、ご案内できません。

数値だけの足切りや、本人の同意なく候補者の人物像を分析すること、組織内の監視・個人の比較は Grift の利用規範に沿わない使い方としています。

候補者ご本人の同意を得て、開発記録について具体的に話す材料として使う方向であれば、テスト導入（PoC）をご相談いただけます。紹介会社・SES 企業向けに個別にご案内しており、料金も使い方を伺ったうえで個別にお伝えします。

なお、Grift CLI 自体は無料の OSS（MIT ライセンス）です。候補者ご本人がご自身のリポジトリで実行できます。インストールには次のコマンドを使います。

pipx install grift-cli

テスト導入の前に、30 分ほどのオンライン打ち合わせで、使い方と候補者から同意をいただく方法を確認したいと考えています。来週から開始できるかはその確認を踏まえてお返事します。
ご都合のよい日時をいくつかお知らせいただけますか。
