先に、できないことを書きます。候補者の方を点数で並べる形では、Grift をご案内できません。Grift は git 履歴から確かめられる事実を取り出す OSS の CLI で、点数、順位、合否を出す作りにしていません。

Grift の利用規範（TEP）は、数値だけでの足切り、同意のない第三者のプロファイリング、組織内の監視や個人の比較を、TEP に沿わない使い方としています。点数の高い順にクライアントへ紹介する使い方は、数値だけの足切りであり、個人の比較です。候補者の方の同意がないまま履歴を扱えば、第三者のプロファイリングになります。

紹介会社・SES 企業の方には、テスト導入（PoC）を個別にご案内しています。料金もその中でご説明します。

始める前に、30 分ほどのオンライン打ち合わせで、使い方と、候補者の方から同意を取る方法を確かめたいと考えています。来週からのご開始は、打ち合わせの日程が決まってからご相談させてください。候補日時をいくつかご提示いただけますか。こちらからも候補を出します。

Grift CLI 自体は無料で、候補者の方ご本人が自分のリポジトリで実行できます。

    pipx install grift-cli

git 履歴から確認できる事実を、面談で具体的に話すための材料として使う。この形であれば、ご相談の範囲に入ります。

まずは打ち合わせの日程をいただければと思います。
