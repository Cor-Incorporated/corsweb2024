経歴書に「テストも書きます」とあったとき、それを確かめる材料はどこにあるでしょうか。

Grift CLIはgit（ソフトウェアの変更の記録を残す仕組み）の履歴から、後で検算できる事実を取り出すOSSです。MITライセンスで、Cor.株式会社が作っています。この記事では自分のリポジトリで動かす手順と、出てくる数字の読み方を書きます。読み手は人材紹介会社・SESの営業の方と、エンジニア本人です。

この記事を書いた時点（2026年10月30日）の公開版は[0.9.1](https://pypi.org/project/grift-cli/)（2026年10月28日公開）です。手順はこの版で書いています。

## 動かす前に知っておくこと

先に、Grift CLIが出さないものを書きます。技量の総合点、シニアやジュニアといったランク、採用の合否は出しません。AIを使って書いたかどうかの検出も、それによる減点もしません。

出すのはgit履歴から数えた件数と率と、その分母です。観測できなかった値は0で埋めず、not_observedやunresolvedとして残します。

git履歴に残っていない仕事も出ません。会議での働きや、履歴として渡されなかったリポジトリの仕事は、この手順では見えません。見えないことと、なかったことは別です。

分析は手元で完結します。LLMを使わず、テレメトリ（利用状況の自動送信）を持たず、結果を自動で送りません。候補者本人の記録を扱う前に、この点を相手に伝えられます。

## 手順

必要なのはPython 3.11以上とgitです。

1. `pipx install grift-cli` で入れます
2. 対象のリポジトリに移動して、`grift report` を実行します
3. `.grift/report.json` と `.grift/report.md` ができます
4. `grift verify` を実行します。レポートに記録された条件で再計算し、一致すれば VERIFIED、違えば MISMATCH を返します。再計算できなければ CANNOT_VERIFY です

最後の検算は、渡された数字が同じ条件で同じ値になるかを確かめる手順です。相手から受け取ったレポートに対しても、同じコマンドで確かめられます。

MISMATCHとCANNOT_VERIFYは別の結果です。MISMATCHは再計算した値が違ったこと、CANNOT_VERIFYは再計算そのものができなかったことを表します。再計算できなかったことを、値が違ったことと読まないでください。

## 数字の読み方

出てきた率は率だけを見ずに、分母と分子から読みます。

2026年8月のQiitaの記事（v0.5.6の時点）で使った例を挙げます。公開OSSのpallets/clickで、test co-change（本番コードの変更と同じコミットでテストも変わった割合）が `0.2664 ratio（73 of 274）` と出ました。

まず274を読みます。本人に帰属した本番コードの変更が274件ありました。次に73です。そのうち73件では同じコミットでテストも変わっていました。`0.2664` は73を274で割った値です。

ここから言えるのは、ここまでです。テストが通った、とは言えません。テストの質が高い、とも言えません。本人が優秀だ、とも言えません。残るのは本番コードの変更274件のうち73件で、同じコミットにテストの変更があった、という事実だけです。

率が低いときも読み方は同じです。テストを書かない人だ、とは言えません。テストを別のコミットで出す流儀かもしれません。その期間の変更にテストが要らなかったのかもしれません。それはgit履歴だけでは決まらないので、面談で聞くことになります。

not_observedやunresolvedが出たときは、0と読まないでください。観測できなかった値を0で埋めると、その項目で相手を低く見ることになります。Grift CLIはそのために、埋めずに残しています。

## 営業の方とエンジニアの方へ

営業の方へ。推薦の理由に数字を添えるときは、率と一緒に分母と分子を書いてください。「test co-changeが0.2664」より、「本番コードの変更274件のうち73件で、同じコミットにテストの変更がある」のほうが、相手は確かめられます。観測できなかった項目は観測できなかったと書きます。

エンジニアの方へ。自分のリポジトリで `grift report` を動かし、`.grift/report.md` を読んでみてください。どの数字が自分の仕事の仕方を表し、どれが表していないか。それは本人がいちばんよく分かります。渡す前にその差を自分の言葉にしておくと、数字だけが独り歩きしません。

判断するのは人です。Grift CLIはその判断に使う事実と、その事実を数え直す手順を残します。

紹介会社・SES企業にはテスト導入（PoC）を個別に案内しています。料金も個別の案内です。
