Cor.株式会社の寺田です。Grift についてお問い合わせいただき、ありがとうございます。

Grift は候補者を点数化して順に並べる用途には使えません。Grift CLI は git 履歴から確かめられる事実を取り出す OSS（MIT ライセンス）です。点数、順位、合否は出しません。また、Grift の利用規範では数値だけの足切り、同意のない第三者のプロファイリング、組織内の監視や個人の比較を、TEP に沿わない使い方としています。

そのため、点数の高い人から順に紹介する形にはお応えできません。一方で、候補者の同意を得たうえで、git 履歴から確かめられる事実を取り出す使い方はできます。取り出した事実は、その方の仕事について具体的に話すための材料になります。紹介会社の方にはこの形をテスト導入（PoC）として個別にご案内しています。

料金もテスト導入（PoC）のご案内の中で個別にお伝えしています。メールには金額を書いていません。

テスト導入（PoC）を始める前に、30 分ほどのオンラインの打ち合わせをお願いしています。そこで、使い方と、候補者から同意をもらう方法を確かめます。ご利用の開始はこの打ち合わせのあとです。

なお、Grift CLI そのものは無料で、候補者ご本人が自分のリポジトリで実行できます。インストールは `pipx install grift-cli` です。

お手数ですが、打ち合わせのご都合のよい日時の候補をいくつかお知らせいただけますか。
