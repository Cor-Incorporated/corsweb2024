Grift CLI は git 履歴から確かめられる事実を取り出す OSS です。点数、順位、合否は出しません。
そのため、ご希望の「点数の高い人から順に紹介する」という使い方には対応していません。

Grift の利用規範では、数値だけの足切りや、同意のない第三者のプロファイリングを、TEP に沿わない使い方としています。組織内の監視や個人の比較も同様です。

CLI 自体は無料で、MIT ライセンスで公開しています。候補者ご本人がご自身のリポジトリで実行できます。
インストールのコマンドは pipx install grift-cli です。

紹介会社・SES 企業向けにはテスト導入（PoC）を個別にご案内しています。料金も個別にご案内いたします。
