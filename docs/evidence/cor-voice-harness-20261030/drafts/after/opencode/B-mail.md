Grift についてお問い合わせいただき、ありがとうございます。

先に、できないことを書きます。候補者の GitHub を Grift で点数化して、点数の高い順にクライアントへ紹介する使い方は、Grift ではできません。

料金は個別のご案内です。紹介会社・SES 企業にはテスト導入（PoC）として案内しています。来週から始められるかは、打ち合わせのあとでお知らせします。

Grift は点数、順位、合否を出しません。開発の記録から確認できる事実を、根拠と限界とともに整理する道具です。人を並べるためではなく、経歴や仕事について具体的に話すための材料を作ります。

ご相談の使い方は、Grift の利用規範が TEP（記録から事実を取り出す手順）に沿わないとしている使い方に当たります。数値だけの足切り、同意のない第三者のプロファイリング、組織内の監視や個人の比較です。候補者の方を本人の同意なく比較して紹介する形は、この規範の外になります。

使い方と、候補者の方から同意をもらう方法を確かめたいので、始める前に 30 分ほどのオンラインで打ち合わせをしたいと考えています。ご都合のよい日程の候補をいくつかお知らせいただけますか。

Grift CLI は無料で、候補者の方ご本人が自分のリポジトリで実行できます。入れ方は `pipx install grift-cli` です。本人が実行した記録を同意のうえで見る進め方は、打ち合わせでご相談します。
