測りたいリポジトリで `grift report` を動かすと、`.grift/report.json` と `.grift/report.md` ができます。数字はそこに並びます。並んだ数字は分母と定義を見ないと読めません。

この記事では、Grift CLI を自分のリポジトリで動かす手順と、出てくる数字の読み方を書きます。読み手は人材紹介会社・SES の営業の方と、エンジニア本人です。

## Grift CLI が出すもの

Grift CLI は git の履歴から、後で検算できる事実を取り出す OSS です。MIT ライセンスで、Cor.株式会社が作っています。

開発の記録から確認できる事実を、根拠と限界とともに整理する道具です。人を点数で並べるためではなく、経歴や仕事について具体的に話すための材料を作ります。

分析は手元で終わります。LLM を使わず、テレメトリを持たず、結果を自動で送りません。

## 動かす準備

Python 3.11 以上と git が要ります。執筆時点の版は 0.9.1 で、2026年10月28日に公開しました（[リリースノート](https://github.com/Cor-Incorporated/grift-cli/releases/tag/v0.9.1)）。

1. Python 3.11 以上と git を用意します
2. `pipx install grift-cli` で入れます
3. 測りたいリポジトリに移動します
4. `grift report` を実行します

`pipx` は、コマンドとして使う Python の道具を入れるための道具です。インストールはこのコマンドだけで終わります。

まず `.grift/report.md` を開いて、数字の横にある分母を探すところから読み始めます。

## 検算する

レポートには、数えたときの条件が記録されます。`grift verify` は、その記録された条件で再計算します。数えた結果を、同じ条件でもう一度数え直す作業です。

結果は、一致すれば VERIFIED、違えば MISMATCH、再計算できなければ CANNOT_VERIFY です。どれも意味が違います。VERIFIED 以外を同じものとして扱いません。

VERIFIED は、記録が完全であることの証明ではありません。同じ条件で数え直して、同じ値になったという意味です。

MISMATCH が出たら、レポートに記録された条件と、数え直したときの条件を並べて見ます。CANNOT_VERIFY は再計算まで届かなかったという意味です。

渡す側も読む側も同じ条件を見て話せます。検算はそのための手順です。

## 数字の読み方

2026年8月のQiitaの記事では、v0.5.6 の時点で、公開 OSS の pallets/click を測った例を出しています。同じコミットでテストも変わった割合（test co-change）は `0.2664 ratio（73 of 274）` でした。

これは、本人に帰属した本番コードの変更 274 件のうち、73 件では同じコミットでテストも変わっていた、という意味です。「本人に帰属した」という条件も、数字と一緒に読みます。誰の変更として記録されているかで、分母は変わります。

読むときに見るのは、比率の小数ではありません。73 と 274 です。分子が何を数えた数で、分母が何のうちなのか。そこが分からないと、比率だけでは何も言えません。

ここから言えないこともあります。テストが通ったとは言えません。テストの質が高いとも言えません。本人が優秀だとも言えません。同じコミットでテストが変わったという、変更の事実だけです。テストの中身が正しいかは、この数字に入っていません。

数字を人に渡すときも同じです。比率だけを渡すと、読み手は分母を想像で補います。何件のうち何件かを、一緒に書きます。

読み始めるときは、次の順で見ます。

1. 指標の定義を読む
2. 分子と分母を確かめる
3. not_observed が混ざっていないか見る

## 0 で埋めない

観測できなかった値は 0 で埋めずに、not_observed や unresolved として残します。

空欄や not_observed を 0 として読みません。0 件だったのか、観測できなかったのかで、意味は変わります。分母の一部が観測できていない数字は、比率だけでは読めません。

## 出さないもの

Grift CLI は技量の総合点を出しません。シニアやジュニアといったランクも出しません。採用の合否も出しません。AI を使ったかどうかの検出や、その減点もありません。

出るのは、記録から数えられる事実と、その分母です。1つの点数にまとめると、何を数えたか、何を数えられなかったかが消えます。

エンジニア本人にとっては、自分の仕事を説明するときの材料になります。分母が小さい指標は、少しの変更で比率が動きます。

営業の方にとっては、推薦の理由を具体的に話すときの材料になります。数字を人に渡す前に、利用規範を一度読みます。

## 紹介会社・SES での利用

人材紹介会社・SES 企業にはテスト導入（PoC）を個別に案内しています。料金も個別の案内です。

まずは手元のリポジトリで一度動かしてみてください。出てきた数字は、分母と定義と一緒に読んでください。
