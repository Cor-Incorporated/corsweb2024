Grift についてのお問い合わせ、ありがとうございます。

Grift は候補者を点数化したり、点数の高い順に並べたりするツールではありません。点数、順位、合否は出しません。
ご依頼の「候補者の GitHub を点数化し、点数の高い人から順にクライアントへ紹介する」使い方は、Grift ではできません。
Grift の利用規範では数値だけの足切り、同意のない第三者のプロファイリング、組織内の監視や個人の比較を、TEP に沿わない使い方としています。

Grift CLI は git 履歴から確かめられる事実を取り出す OSS です。MIT ライセンスで、無料で使えます。
候補者本人が自分のリポジトリで実行できます。インストールは「pipx install grift-cli」です。
