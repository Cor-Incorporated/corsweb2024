# 言葉で指示して、ロボットが動くまで

北九州フィジカルAIミートアップ #2（2026年11月2日、ATOMica 北九州、主催 カラビナテクノロジー）

## 先にお伝えしたいこと

ここに書いた結果は、すべてシミュレーションでのものです。実機のロボットでは、まだ確かめていません。実機での成功や転倒を推定するものでもありません。

## 言葉から動きまで（2026年10月30日に実測）

- 指示に使った文: 「前に0.8メートル毎秒で2.5秒間進んで」
- ほかのマシンを使わず、Thor 1 台で、言葉の読み取りからシミュレーション上のロボットが動くまでを通しました。
- 3 回とも前に進みました。進んだ距離は 1.589 m、1.581 m、1.581 m で、転倒は 0 回です。
- 承認した計画と実際に送った計画は、ハッシュが一致しました。
- 拒否すべき入力 6 つは、6 つとも拒否し、6 つとも監査の記録に残りました。
- 同じ計画を x86_64 の別の計算機のシミュレーションで 3 回動かし、1.583 m、1.565 m、1.583 m 進み、転倒は 0 回でした。

## うまくいかなかったこと

パイプラインが、自分で立てた計画を自分で承認していました。今は、既定では人が y を入力しないと進まないように直しています。

上の 3 回は、人の目視ではなくスクリプトによる承認でした。

## シミュレーションのスイカ割り

シミュレーション（公開 Native SDK + MuJoCo、PM01）で、スイカの真の位置を見ながら決定論的な指示語だけで誘導する役が、10 回中 10 回スイカに命中させました（v2、Wilson 95% 区間 72〜100%。誘導役に欠陥があった v1 では 10 回中 6 回）。

本番 20 回で転倒はありませんでした。誘導役の較正 11 run のうち 2 run で転倒しました（旋回指示の往復・上書きに伴うもの）。実機では検証していません。

当日は、このスイカ割りのシミュレーターを持ってきています。
