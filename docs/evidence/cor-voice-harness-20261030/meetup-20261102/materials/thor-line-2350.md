# Thor レーンの 23:50 版（統括セッション経由、2026-10-30）

23:45 版（`thor-line-2345.md`）に足す事実。数字は 23:45 版とここにあるものだけを使う。提供元の社名と、社名を含む学習環境の名前は、公開リポジトリなので伏せて「提供元の RL の学習環境」と書いた。

- 重みは、提供元の RL の学習環境の run `2026-09-14_22-46-03` の MNN に固定した（GB10 の Isaac Sim で再生した `model_19999` と同じ run）。SDK に同梱の `pm01_amp_walk.mnn` は、出どころの run が分からないので対照にだけ使った
- sim2sim: Thor と同じ arm64 の SDK ビルドで、その重みを公開 SDK の rl_lab runner に載せ、MuJoCo の PM01 を 10 秒歩かせた。4/4 で直立のまま前進（+4.14 / +4.30 / +4.33 / +4.26 m、腰の高さの最小 0.796 m、転倒 0）。対照の SDK 同梱の方策は +4.32 m、転倒 0
- この sim2sim は、Thor と同じ arm64 の image を Mac の Docker で動かして測った値。Thor の上での実行はこれから（配置待ち）。原稿では「Thor と同じビルドで」と書き、Thor の上で測ったあとに差し替える 1 行を予備に置く
- 話の筋: Isaac Sim / Isaac Lab（GB10）で提供元の学習済み方策を再生 → 同じ重みを公開 SDK の runner で MuJoCo に載せても立ったまま歩く（sim2sim 4/4）→ Thor では SDK の MNN 方策が CPU で PM01（シミュレーション）を歩かせ、スイカを割る → 実機は次の段階
- MNN は第三者の成果物で、リポジトリには入れていない。Isaac Sim の録画は 6 秒の版
