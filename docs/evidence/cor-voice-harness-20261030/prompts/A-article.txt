資料:
- Grift CLI は、git 履歴から後で検算できる事実を取り出す OSS です。MIT ライセンスで、Cor.株式会社が作っています。
- 執筆時点の版は 0.9.1（2026-10-28 公開）です。Python 3.11 以上と git が要ります。
- 入れ方は `pipx install grift-cli` です。対象のリポジトリで `grift report` を実行すると、`.grift/report.json` と `.grift/report.md` ができます。
- `grift verify` は、レポートに記録された条件で再計算し、一致すれば VERIFIED、違えば MISMATCH、再計算できなければ CANNOT_VERIFY を返します。
- 出さないものは、技量の総合点、シニア／ジュニアなどのランク、採用の合否、AI を使ったかどうかの検出や減点です。観測できなかった値は 0 で埋めず、not_observed や unresolved として残します。
- 2026 年 8 月の Qiita 記事（v0.5.6 の時点）で使った例: 公開 OSS の pallets/click で、test co-change が `0.2664 ratio（73 of 274）` と出ました。本人に帰属した本番コードの変更 274 件のうち、73 件では同じコミットでテストも変わっていた、という意味です。ここから、テストが通った、テストの質が高い、本人が優秀だ、とは言えません。
- 分析は手元で完結します。LLM を使わず、テレメトリを持たず、結果を自動で送りません。
- 紹介会社・SES 企業には、テスト導入（PoC）を個別に案内しています。料金も個別の案内です。
