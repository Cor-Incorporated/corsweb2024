資料（grift-cli の PR #115 の README の追記から。2026-10-30 時点）:
- ホストに Python を入れずに、grift-cli のリポジトリを clone して作ったイメージで grift を実行できる。読みたいリポジトリは `/repo` に mount する。
- 例: `docker build -t grift-cli grift-cli`、`docker run --rm -v "$PWD:/repo:ro" grift-cli repo`
- 履歴は全部取得する。`git worktree` で作った作業ツリーは mount しない（コンテナ内から履歴を読めず exit 2 で止まる）。
- イメージには `git` と `openssh-client` だけを入れ、`gh` と `cosign` は入れない。
