# ADR-0011 有料入口 CTA・情報設計・050 AI受付の表示方針

## ステータス: Accepted (2026-07-10)

## 背景
- 更新予定 Cor で「無料で相談する」が主 CTA に残り、v0.5 の有料入口（機密データAI活用診断 10万〜30万円等）と競合する（監査 P0-3）。
- Header が実績・ニュース・ブログ・問い合わせ中心で、サービス導線が弱い（Security は develop で既に一部追加済み）。
- 050-1792-9351 の AI 受付はテスト完了前に番号だけ出さない。

## 決定

### 主 CTA は 3 本に固定
1. **機密データAI活用診断を相談する**（`intent=confidential-ai-assessment`）
2. **ローカルLLM / セキュアAI PoCを相談する**（`intent=local-llm-poc`）
3. **Grift Team Beta / Estimate Auditを相談する**（`intent=grift-team-beta` または `estimate-audit`）

- 「無料30分相談」「無料で相談する」は **トップの主 CTA にしない**。
- 無料枠は紹介限定・高適合リード・診断前の確認に限定し、文言・配置を弱くする。

### Header IA（推奨。2026-07-10 時点。下の「Header IA の改訂」で置き換えた）
- サービス
  - 機密データAI活用診断
  - ローカルLLM / セキュアAI PoC
  - AI基盤構築・AI受託
- 業種別
- 実績・事例
- セキュリティ
- 会社情報
- Cloudiaに相談（→ `/contact/` またはフローティング）

### Header IA の改訂（2026-10-24）
パソコンのヘッダーにブログと About がなく、スマホのメニューからしか行けなかった（代表の指摘）。パソコンのヘッダーを次の並びにする。スマホのメニューも同じ順に並べ、そのあとに業種別とお問い合わせを置く。
- サービス（プルダウン）: 機密データAI活用診断 / ローカルLLM / セキュアAI PoC / AI基盤構築・AI受託 / Grift
- 実績・事例
- ブログ
- Cor.について（プルダウン）: Cor.株式会社について / 会社概要 / セキュリティ / ニュース / プレスリリース
- お問い合わせ

業種別はパソコンのヘッダーから外し、トップの業種の欄とスマホのメニューから入る。実装は `src/components/layout/Header.astro`。

### ホーム思想セクション
- トップの 5 語「共創・協奏・競争・狂想・狂騒」は情報量が多い。「狂想」「狂騒」は About へ。
- トップでは次の 3 原則に絞る: 課題を先に整理する / 運用まで設計する / 必要なら作らない判断も提案する。
- Hero の「御用聞きではなく」は「必要なら、作らない判断も含めてご提案します」へ寄せる。

### About 代表
- 経歴は「音楽家 → 法人営業 → IT起業」の 2 文程度。長い個人史は Founder Story 任意。
- 主語は顧客課題と Cor の実装。GitHub / YouTube / connpass 等の検証可能リンクを置く。

### 050 AI受付
- 内部予定番号: `050-1792-9351`。
- **着信・転送・録音案内・個人情報ガード・ログ権限・PP/弁護士確認が終わるまで公開番号を切り替えない**。
- 表示文案（テスト後）:

> 050-1792-9351（AI受付）  
> AIがご用件を整理し、必要に応じて担当者へおつなぎします。録音・文字起こしを行う場合は通話冒頭でご案内します。

## 理由
- 有料入口と無料主 CTA の競合はリード品質と単価を下げる。
- 購入判断者はサービスとセキュリティに先に行きたい。
- 未検証の AI 電話番号公開は法務・顧客体験リスク。

## 影響
- i18n CTA 文言、Header、About、ContactInfo を Issue で更新。
- 050 は独立 Issue（公開ゲートの依存条件付き）。

## 代替案
- **無料相談を主 CTA に残す**: 戦略 v0.5 と矛盾するため却下。
- **050 を先行表示**: テスト未完了のため却下。
