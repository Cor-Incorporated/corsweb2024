## 과제

이 설문 수집·분석 플랫폼은 Cor.가 중간에 이어받은 프로젝트입니다. 인계받을 당시에는 테스트 환경이 제대로 갖춰져 있지 않고 배포 절차도 정립되어 있지 않아, 기능을 하나 추가할 때마다 다른 부분에 미치는 영향을 확인하는 작업에 많은 시간이 소요되고 있었습니다. 정적인 설문 양식을 넘어 AI가 대화하며 응답을 심층적으로 파고드는 경험을 지향하고 싶었으나, 애초에 안심하고 변경을 가할 수 있는 상태가 아니었다는 점이 첫 번째 걸림돌이었습니다.

## 접근 방식

Cor.는 무작정 처음부터 다시 만들기보다는 '안전하게 변경할 수 있는 상태'를 먼저 만드는 것을 선택했습니다. 기능 추가보다 앞서 테스트와 CI/CD, 인프라 코드 관리를 정비하여 기반을 다진 뒤, 핵심인 AI 대화 기능에 착수하는 순서였습니다. 이와 더불어 누가 무엇에 접근할 수 있는지에 대한 권한 관리와 데이터 취급 방식도 이 단계에서 다시 정리했습니다.

## 구현

기술 기반은 Python / FastAPI / PostgreSQL로 구성하고, 복수의 LLM을 전환할 수 있는 구조로 만들었습니다. AI 에이전트 부분은 Google의 에이전트 개발 키트(ADK)로의 마이그레이션을 진행했으며, 인프라는 Terraform을 통한 코드 관리로 전환했습니다. 인증 기반도 쇄신하여 권한 관리와 접근 권한 정리도 함께 진행했습니다. 테스트는 약 2,500건을 정비하고 CI/CD 워크플로는 27개를 운용하며, 로그와 트레이스를 통한 관측 가능성(Observability)도 확보했습니다.

- 기술: Python / FastAPI / PostgreSQL, 복수 LLM 전환 구조, Google ADK, Terraform
- 품질·운영: 테스트 약 2,500건, CI/CD 워크플로 27개, 관측 가능성, 권한 관리 쇄신

## 성과

인계 후 단계(2025년 11월~2026년 3월)에서는 커밋의 77.5%(git 실측)를 Cor.가 담당하여 기반 재구축부터 AI 대화 기능의 상용화까지 추진했습니다. 현재 배포 빈도는 일평균 2.5회이며, 풀 리퀘스트의 리드 타임 중앙값은 24분까지 단축되었습니다. 실제 활용은 484건·12개 프로젝트에 도달했습니다. 테스트와 CI/CD를 먼저 탄탄히 구축함으로써 기능이 추가될 때마다 긴장할 필요가 없어졌고, '변경이 두렵지 않은 기반'으로 탈바꿈한 것이 가장 큰 성과라고 생각합니다.
