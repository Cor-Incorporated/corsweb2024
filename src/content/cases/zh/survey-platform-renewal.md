## 课题

这个问卷收集与分析平台是 Cor. 中途接手的项目。在接手时，测试体系尚不完善，部署流程也未确定，每增加一个功能都需要花费大量时间去确认对其他部分的影响。虽然目标是超越静态表单，打造由 AI 进行对话并深入挖掘回答的体验，但系统本身甚至无法让人安心地进行变更，这构成了最初的阻碍。

## 方法

Cor. 没有选择直接推倒重来，而是优先构建“能够安全进行变更的状态”。在添加新功能之前，先完善了测试、CI/CD 以及基础设施的代码化管理，在稳固基础之后再着手核心的 AI 对话功能。同时，在这个阶段也重新梳理了权限管理与数据处理流程，明确了人员的访问权限。

## 实现

技术底座采用 Python / FastAPI / PostgreSQL 构建，并支持在多个 LLM 之间切换。AI Agent 部分推进了向 Google Agent 开发套件 (ADK) 的迁移，基础设施则切换为基于 Terraform 的代码化管理。同时更新了认证体系，重新梳理了权限管理与访问控制。编写了约 2,500 项测试，运行 27 条 CI/CD 工作流，并通过日志和链路追踪完善了可观测性。

- 技术：Python / FastAPI / PostgreSQL、多 LLM 切换架构、Google ADK、Terraform
- 质量与运维：约 2,500 项测试、27 条 CI/CD 工作流、可观测性、权限管理重构

## 成果

在接手后的阶段（2025年11月～2026年3月）中，Cor. 承担了 77.5% 的提交量（git 实际测算），推进了从底座重建到 AI 对话功能正式上线的全过程。目前平均每天部署 2.5 次，Pull Request 的交付时间中位数缩短至 24 分钟。实际使用量已达 484 笔、覆盖 12 个项目。通过优先稳固测试与 CI/CD，不再需要在每次添加功能时提心吊胆，平台转变为了“无惧变更的基础架构”，我们认为这是最大的成果。
