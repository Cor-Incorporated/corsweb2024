# 【神速15分钟】用MCP服务器制作MCP服务器！“贴心搞定一切的应用”开发秘闻

7月最后一天的傍晚，岩盘浴带来的暖意在瞬间凉透。随着第60周的LT活动突遭取消，这个故事就此拉开序幕。
![因LT取消而大受打击的推文](/images/blog/スクリーンショット-2025-08-02-18.25.01.avif)

## 绝境中的大逆转

每周从未间断过的LT登台分享。就在值得纪念的第60周前夕，竟然收到了取消通知。但这绝不能轻言放弃。为了给年末年初时惨淡收场的YouTube直播打一场翻身仗，我决定紧急举办一个极其硬核的策划。

“**在2小时内充分运用AI工具，根据题目进行vibe coding并完成部署，最后30分钟制作幻灯片进行LT分享的YouTube直播**”

![YouTube直播策划](/images/blog/スクリーンショット-2025-08-02-18.52.51.avif)

在X上征集题目后，各种天马行空的刁钻难题纷至沓来。顺利解决掉两个题目后，距离21点开始做幻灯片只剩最后15分钟。最后再次转动轮盘，命运的题目赫然出现。

大脑瞬间宕机。只剩15分钟，这该怎么实现？

## 用MCP服务器制作MCP服务器的禁忌绝招

在绝望的境地中，灵光一闪。我的Claude Desktop中已经注册了作为MCP服务器的“Claude Code”。而现在需要的恰好也是一个MCP服务器。也就是说，**直接用MCP服务器来做MCP服务器不就行了**。

我决定挑战这种嵌套结构的实现。YouTube直播不能停。在观众们的注视下，我孤注一掷。

```javascript
// 実際に生成されたコードの一部
const randomElements = {
  folders: [
    '秘密の花園',
    '迷子の思い出',
    '月曜日の憂鬱',
    '金曜日の解放感',
    '開かずの間',
    'なんとなく大事そう'
  ],
  
  actions: [
    'createRandomFolder',
    'createArtFolder',
    'renameRandomFile',
    'hideSecretFile',
    'createTimeCapule'
  ]
};
```

## 15分钟诞生的奇迹应用

Claude Code没有让人失望。一行代码未写，仅仅通过对话，一个具备以下功能的MCP服务器便诞生了。

### 实现的7个随机动作

1. 随机创建文件夹：生成诸如“周一的忧郁”、“周五的解脱感”等充满诗意的文件夹名称
2. 随机创建文件：自动生成俳句、运势、购物便签等
3. 文件整理：将图片文件避难转移至“找到的宝藏”文件夹
4. 文件重命名：将屏幕截图重命名为“可能很重要.png”等
5. 桌面美术馆：展示ASCII字符画构成的现代艺术作品
6. 创建秘密文件：生成名为`.secret_treasure.txt`的隐藏文件
7. 时间胶囊：撰写一条写给1年后自己的留言

### 生成内容示例

```text
// 俳句
デスクトップに
散らばるファイル
夏の空

// 買い物メモ
- 牛乳
- パン
- 整理整頓の本
- やる気（売ってたら）
- 時間（これも売ってたら）

// デスクトップ哲学
「完璧に整理されたデスクトップは、
 使われていないデスクトップである」
- 誰か偉い人（たぶん）
```

## 神秘的HTML UI实现事件

最让人捧腹的是，Claude Code竟然擅自实现了一套HTML UI。也许是因为需求里提到了“应用”，最终呈现出一个看起来能动态运行的完整Web界面。然而，这个MCP服务器只能通过Claude Desktop使用。结果这个UI完全派不上用场，只是静静地存在于那里。

问AI为什么要实现它，也得不到任何回答。

## 投入实战的结果

将制作完成的MCP服务器注册到Claude Desktop中并运行。令人惊讶的是，一次就顺利跑通了。

### 第1次运行：桌面美术馆开馆
```

🎨 「デスクトップ美術館」を開館しました！芸術作品も展示済みです
```

桌面上突然出现了一个美术馆文件夹。里面端坐着ASCII字符画风格的现代艺术作品。

### 第2次运行：屏幕截图的命运
```
✨ いい感じにアレしておきました！

🏷️ 「スクリーンショット_2024-08-01.png」を「たぶん重要.png」にリネームしました！
```

大量的屏幕截图文件夹在一瞬间变成了“可能很重要.png”。也许确实很重要，也许并没有。

## 技术层面的收获

看似荒诞不经，实际上却带来了几个重要的发现。

### 1. MCP（Model Context Protocol）的潜力
MCP服务器的实现比想象中要简单得多。像本次这样“对桌面做点小操作”的程度，15分钟绰绰有余。

### 2. 用AI进行AI开发成为现实
通过Claude Code来开发MCP服务器这种嵌套结构，让我们窥见了AI创造AI的未来。在这个过程中，人类所做的仅仅是提出创意，具体的实现则完全交给了AI。

### 3. 截止时间驱动开发的威力
仅剩15分钟的极限状态，反而彻底激发了创造力。如果有充裕的时间，往往会试图去做一个“像样”的东西，结果大概会变得索然无味。

### 实现要点

```javascript
class IikanjiServer {
  async handleIikanjini(args) {
    const desktopPath = args.desktopPath || path.join(os.homedir(), 'Desktop');
    
    // ランダムなアクションを選択
    const action = randomElements.actions[
      Math.floor(Math.random() * randomElements.actions.length)
    ];
    
    // 各アクションを実行
    switch (action) {
      case 'createArtFolder':
        result = await this.createArtFolder(desktopPath);
        break;
      // ... 他のアクション
    }
    
    return {
      content: [{
        type: 'text',
        text: `✨ いい感じにアレしておきました！\n\n${result}`,
      }],
    };
  }
}
```

结构虽然简单，但这足以构成一个能从Claude Desktop直接调用的合格MCP服务器。

## vibe coding催生的创造力

这次经历让我深信不疑。比起追求技术上的准确性和完备度，凭借当下的兴致与冲劲去开发的“vibe coding”，有着其独特的魅力。

- 正如15分钟的时间限制催生了新奇的构想一样，限制反而能激发创造力
- 不追求完美、抱持着“差不多就好”的模糊感，反而能带来趣味性
- 将乐趣置于首位，比起实用性，更看重“做起来很开心”

## 总结：制作脑洞大开之物的乐趣

从技术角度来看，“随便搞搞就好了应用”是一个极其简单的MCP服务器。然而，它的构思、实现过程，以及产生结果的不可预测性，赋予了这款应用独特的色彩。

这个在LT活动取消的绝望中诞生的应用，展现了截止时间驱动开发的潜力，以及AI时代全新的开发风格。MCP服务器可以用AI来制作。而且，做一些脑洞大开的东西，果然非常开心。

下次如果你的桌面也乱成一团，不妨试着拜托它“帮我随便搞搞”吧。相信它一定会以意想不到的方式，帮你随便搞搞好。

不过，操作结果是不可逆的，如果有重要文件请务必小心。但话说回来，这也是人生的一部分嘛。
