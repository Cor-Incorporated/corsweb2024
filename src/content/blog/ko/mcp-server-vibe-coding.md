# 【초고속 15분】 MCP 서버로 MCP 서버를 만든다! '알아서 척척 해주는 앱' 개발 비화

암반욕으로 노곤노곤해졌던 기분이 순식간에 차게 식어버린 7월 마지막 날의 해질녘. 60주 차 LT 이벤트가 돌연 취소된 순간부터, 이 이야기는 시작된다.
![LT 취소에 충격을 받은 트윗](/images/blog/スクリーンショット-2025-08-02-18.25.01.avif)

## 절망에서 피어난 대역전극

매주 거르지 않고 이어오던 LT 등단. 기념비적인 60주 차를 눈앞에 두고 맞닥뜨린 뜻밖의 취소 통보. 하지만 이대로 포기할 수는 없었다. 연말연시에 대폭망했던 YouTube LIVE의 설욕전으로서, 엄청난 기획을 긴급 개최하기로 했다.

「**2시간 동안 AI 툴을 총동원해 제시된 주제로 vibe 코딩을 진행하여 배포까지 마치고, 마지막 30분 동안 슬라이드를 만들어 LT를 진행하는 YouTube LIVE**」

![YouTube LIVE 기획](/images/blog/スクリーンショット-2025-08-02-18.52.51.avif)

X에서 주제를 모집하자 쏟아져 들어오는 무수한 무리한 요구들. 순조롭게 2개의 주제를 소화하고, 21시 슬라이드 제작 시작까지 남은 시간은 15분. 마지막으로 룰렛을 한 번 더 돌리자, 운명의 주제가 화면에 떴다.

![「『알아서 대충 처리해 줘』라고 부탁하면, 데스크톱 위의 무언가를 무작위로 골라 알아서 대충 처리해 주는(돌이킬 수 없음) 앱」](/images/blog/スクリーンショット-2025-08-02-20.15.01.avif)

순간 뇌 정지가 왔다. 남은 15분 안에 이걸 어떻게 구현한단 말인가.

## MCP 서버로 MCP 서버를 만드는 금단의 기술

절망적인 상황 속에서 문득 묘안이 떠올랐다. Claude Desktop에는 MCP 서버로 「Claude Code」를 등록해 두었다. 그리고 지금 필요한 것도 MCP 서버다. 다시 말해, **MCP 서버를 사용해 MCP 서버를 만들면 된다**.

이 중첩 구조의 구현에 도전하기로 했다. YouTube LIVE는 멈출 수 없다. 시청자들이 지켜보는 가운데, 모 아니면 도의 도박에 나섰다.

```javascript
// 実際に生成されたコードの一部
const randomElements = {
  folders: [
    '秘密の花園',
    '迷子の思い出',
    '月曜日の憂鬱',
    '金曜日の解放感',
    '開かずの間',
    'なんとなく大事そう'
  ],
  
  actions: [
    'createRandomFolder',
    'createArtFolder',
    'renameRandomFile',
    'hideSecretFile',
    'createTimeCapule'
  ]
};
```

## 15분 만에 완성된 기적의 앱

Claude Code는 기대를 저버리지 않았다. 코드를 한 줄도 작성하지 않고 오직 대화만으로 다음 기능을 갖춘 MCP 서버가 완성되었다.

### 구현된 7가지 무작위 액션

1. 무작위 폴더 생성: 「월요일의 우울」, 「금요일의 해방감」 같은 시적인 이름의 폴더 생성
2. 무작위 파일 생성: 하이쿠, 운세, 쇼핑 메모 등을 자동 생성
3. 파일 정리: 이미지 파일을 「발견한 보물」 폴더로 대피
4. 파일 이름 변경: 스크린샷을 「아마도_중요.png」 등으로 변경
5. 데스크톱 미술관: 아스키아트(ASCII Art) 현대 미술 작품 전시
6. 비밀 파일 생성: `.secret_treasure.txt`라는 숨김 파일 생성
7. 타임캡슐: 1년 후의 자신에게 보내는 메시지 작성

### 생성되는 콘텐츠 예시

```text
// 俳句
デスクトップに
散らばるファイル
夏の空

// 買い物メモ
- 牛乳
- パン
- 整理整頓の本
- やる気（売ってたら）
- 時間（これも売ってたら）

// デスクトップ哲学
「完璧に整理されたデスクトップは、
 使われていないデスクトップである」
- 誰か偉い人（たぶん）
```

## 의문의 HTML UI 구현 사건

가장 웃겼던 점은 Claude Code가 제멋대로 HTML UI를 구현해 놓았다는 것이다. 「앱」이라고 요청해서인지, 겉보기에는 동적으로 움직이는 훌륭한 웹 인터페이스가 완성되어 있었다. 하지만 이 MCP 서버는 Claude Desktop을 통해서만 사용할 수 있다. 결국 UI는 전혀 사용되지 않은 채 그저 그 자리에 존재할 뿐이었다.

왜 구현했는지 AI에게 물어봐도 대답은 돌아오지 않는다.

## 실전 투입 결과

완성된 MCP 서버를 Claude Desktop에 등록하고 실행했다. 놀랍게도 단 한 번에 아무런 문제 없이 작동했다.

### 1회 차 실행: 데스크톱 미술관 개관
```
✨ いい感じにアレしておきました！

🎨 「デスクトップ美術館」を開館しました！芸術作品も展示済みです
```

데스크톱에 갑자기 나타난 미술관 폴더. 안에는 아스키아트 현대 미술 작품이 위풍당당하게 자리 잡고 있었다.

### 2회 차 실행: 스크린샷의 운명
```
✨ いい感じにアレしておきました！

🏷️ 「スクリーンショット_2024-08-01.png」を「たぶん重要.png」にリネームしました！
```

대량의 스크린샷 폴더가 순식간에 「아마도_중요.png」로 변경되었다. 확실히 중요할 수도 있고, 아닐 수도 있다.

## 기술적인 배움

언뜻 장난처럼 보이지만, 실제로는 몇 가지 중요한 발견이 있었다.

### 1. MCP(Model Context Protocol)의 가능성
MCP 서버는 생각보다 훨씬 간단하게 구현할 수 있다. 이번처럼 「데스크톱을 다루는」 수준이라면 15분이면 충분하다.

### 2. AI에 의한 AI 개발의 실현
Claude Code로 MCP 서버를 만드는 중첩 구조는 AI가 AI를 만드는 미래를 엿보게 해 주었다. 이번에 인간이 한 일은 아이디어를 낸 것뿐이었고, 구현은 전부 AI에게 맡길 수 있었다.

### 3. 마감 주도 개발의 위력
남은 시간 15분이라는 극한의 상황이 오히려 창의성을 폭발시켰다. 시간이 넉넉했다면 「제대로 된」 것을 만들려고 하다가 분명 재미없는 결과물이 나왔을 것이다.

### 구현 포인트

```javascript
class IikanjiServer {
  async handleIikanjini(args) {
    const desktopPath = args.desktopPath || path.join(os.homedir(), 'Desktop');
    
    // ランダムなアクションを選択
    const action = randomElements.actions[
      Math.floor(Math.random() * randomElements.actions.length)
    ];
    
    // 各アクションを実行
    switch (action) {
      case 'createArtFolder':
        result = await this.createArtFolder(desktopPath);
        break;
      // ... 他のアクション
    }
    
    return {
      content: [{
        type: 'text',
        text: `✨ いい感じにアレしておきました！\n\n${result}`,
      }],
    };
  }
}
```

단순한 구조이지만, 이것만으로도 Claude Desktop에서 호출할 수 있는 어엿한 MCP 서버가 된다.

## vibe coding이 만들어내는 창의성

이번 경험을 통해 확신했다. 기술적인 정확성이나 완성도를 추구하기보다 그 자리의 느낌과 흐름을 타고 만드는 「vibe coding」에는 독특한 매력이 있다.

- 15분이라는 시간제한이 참신한 아이디어를 낳았듯, 제약은 창의성을 만든다
- 완벽을 바라지 않는 「알아서 대충」이라는 모호함이 오히려 재미를 낳는다
- 즐거움을 최우선으로 두고, 실용성보다는 「만들면서 즐거운 것」을 중시한다

## 맺음말: 엉뚱하고 기발한 것을 만드는 즐거움

「알아서 대충 처리해 주는 앱」은 기술적으로는 매우 단순한 MCP 서버다. 하지만 그 발상과 구현 과정, 그리고 만들어지는 결과의 예측 불가능성이 이 앱을 특별하게 만들어 준다.

LT 이벤트 취소라는 절망 속에서 탄생한 이 앱은 마감 주도 개발의 가능성과 AI 시대의 새로운 개발 방식을 보여주었다. MCP 서버는 AI로 만들 수 있다. 그리고 엉뚱하고 기발한 것을 만드는 일은 역시나 즐겁다.

다음번에 데스크톱이 어질러져 있다면, 「알아서 대충 처리해 줘」라고 부탁해 보는 것은 어떨까. 분명 예상치 못한 방식으로 알아서 대충 처리해 줄 것이다.

단, 결과는 돌이킬 수 없으므로 중요한 파일이 있다면 주의가 필요하다. 하지만 그것 또한 인생이다.
